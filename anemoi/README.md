# Anemoi integration
The anemoi-graphs [https://anemoi.readthedocs.io/projects/graphs/en/latest/index.html](https://anemoi.readthedocs.io/projects/graphs/en/latest/index.html) integrations lets users upload single level `graph.pt` files generated by anemoi.

To generate a graph, one defines a graph like described in the documentation in a recipe.yaml:
```yaml
nodes:
  data:
    node_builder:
      _target_: anemoi.graphs.nodes.AnemoiDatasetNodes
      dataset: https://data.ecmwf.int/anemoi-datasets/era5-o96-1979-2023-6h-v8.zarr
  hidden:
    node_builder:
      _target_: anemoi.graphs.nodes.TriNodes
      resolution: 5

edges:
  # A) Encoder connections
  - source_name: data
    target_name: hidden
    edge_builders:
    - _target_: anemoi.graphs.edges.CutOffEdges
      cutoff_factor: 0.7
  # B) Decoder connections
  - source_name: hidden
    target_name: data
    target_mask_attr_name: cutout
    edge_builders:
    - _target_: anemoi.graphs.edges.KNNEdges
      num_nearest_neighbours: 3
 # C) Processor connections
  - source_name: hidden
    target_name: hidden
    edge_builders:
    - _target_: anemoi.graphs.edges.MultiScaleEdges
      x_hops: 1
```

Use the names data for the for the grid and hidden (and hidden_l[i] for `i`-layer) fot the hidden layers.

Then in an environment with the following packages: `anemoi-graphs`, `anemoi-datasets`, `netCDF4` and `trimesh` one generates the graph:
```bash
anemoi-graphs create anemoi/recipe.yaml anemoi_multiscale/graph.pt
```

or for hierarchical
```bash
anemoi-graphs create anemoi/recipe_hierarchical.yaml anemoi_hierarchical/graph.pt
```

With
```bash
anemoi-graphs inspect anemoi_multiscale/graph.pt
```
one can also inspect the graph (and open the `graph.html` file in a browser.)

The user then can uplaod the `graph.pt` file to the tool to inspect it.
